# Used Cars and Trucks for Sale

**A Free Bot Connecting Buyers & Sellers in Lansing, Michigan**

## About
Used Cars and Trucks for Sale is a marketplace bot that connects buyers with affordable vehicles within a 50-mile radius of Lansing, Michigan. We work as facilitators between buyers, private sellers, and dealerships — helping you find the right vehicle at the right price.

## How It Works

### For Buyers:
1. Search for vehicles on Telegram or Web
2. Filter by budget, type (car/truck), location
3. Get matched with available inventory
4. Express interest and we facilitate the connection
5. Once you purchase, you pay a flat $100 fee to us

### For Sellers (Dealerships & Private):
1. List your vehicles through us
2. We connect you with qualified buyers
3. Once the sale is complete, you pay us a flat $100 fee
4. No refunds — payment due at time of sale completion

### For Facilitator (Me):
- I source vehicles from dealerships, private sellers, and auctions
- I match buyers with vehicles
- I facilitate the deal (not the seller, not a pushy salesperson)
- I get paid $100 from buyer + $100 from seller = $200 per deal
- All payments happen simultaneously when the sale closes

## Key Features

✅ **Telegram Bot** - Search, filter, express interest on-the-go  
✅ **Web Interface** - Browse inventory on Google Maps  
✅ **Real-Time Updates** - Inventory syncs from multiple sources daily  
✅ **Google Maps Integration** - See vehicle locations instantly  
✅ **Multi-Channel Input** - Google Form, Email, Text, Google Sheet  
✅ **Google Voice Routing** - All inquiries go to your phone  
✅ **Simple Pricing** - $100 flat fee per deal (no hidden costs)  
✅ **Work from Home** - Manage everything remotely  

## Technology Stack

- **Backend:** Node.js + Express + TypeScript
- **Frontend:** React + Tailwind CSS
- **Database:** Firebase (free tier)
- **Maps:** Google Maps API
- **Bot:** Telegram Bot API
- **Hosting:** Vercel (frontend) + Railway/Render (backend)
- **Contact:** Google Voice integration
